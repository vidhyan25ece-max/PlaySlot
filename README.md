# PlaySlot

### Smart & Simple Sports Slot Booking Platform

PlaySlot is a user-friendly sports facility booking platform designed to make finding and reserving sports slots quick, simple, and hassle-free.

Whether you're looking to book a game with friends or manage your upcoming reservations, PlaySlot brings everything together in one convenient platform.

## Source Code

This repository contains the complete frontend and backend source code of PlaySlot, including the application's interface, server-side functionality, and database integration.

## What PlaySlot Offers

* Simple user login
* Sports slot discovery and booking
* Easy reservation management
* Fast and user-friendly interface
* Online deployment for easy access
* PostgreSQL database integration

## Technology Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js
* Database: PostgreSQL
* Deployment: Netlify and Render
